# Michael Shadpour

Developer & designer. I design and build websites, mobile apps, Chrome extensions and desktop
software, mostly in TypeScript and Python, and the brands that go with them. Founder of
[Gidion](https://gidion.io).

**Portfolio → [michaelshadpour.com](https://michaelshadpour.com)**, a 3D museum you can walk

### Selected work

- **[Agnos](https://agnos.cloud)**: a Windows app on the Microsoft Store that cleans documents before they reach an AI. Python, Flask.
- **[Starling](https://michaelshadpour.com/work/starling)**: a Chrome extension that drafts replies, quotes and posts on X in your own voice. You press Post, never Starling. About 5,500 automated tests.
- **[Spoody Tracker](https://michaelshadpour.com/work/spoody-tracker)**: a live, pixel-art world map of Spider-Man sightings. Built in ten days with Preact, MapLibre and Supabase; an unofficial fan project, open source (MIT).
- **[Everwick](https://michaelshadpour.com/work/everwick)**: a calm habit tracker for iOS and Android (concept project). Expo, React Native, about 400 tests.
